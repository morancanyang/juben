# DeepSeek NPC 接入

## 配置

在项目根目录 `.env` 设置（不要提交此文件，也不要把密钥写入 `web/`）：

```dotenv
PROVIDER=deepseek
DEEPSEEK_API_KEY=你的有效
DEEPSEEK_MODEL=deepseek-flash
MODEL_TIMEOUT_SECONDS=18
MODEL_DAILY_CALL_LIMIT=100
```

修改后必须重启 FastAPI 进程；设置页面的“角色回答模式”会显示已配置的 DeepSeek。

## 每个 NPC 收到的上下文

每次对话只发送当前角色的 ID、姓名、职位、性格、当前问题、该角色最近 12 条聊天消息、当前已解锁且满足条件的证词目录，以及该角色之前选过的证词 ID。完整答案、隐藏证物、其他角色的私密内容和未授权笔记不会发送。

## 模型输出协议

模型必须返回 JSON：

```json
{"statement_ids":["lin_1"],"tone":"calm","reply":"自然改写后的角色回答"}
```

服务端先检查 `statement_ids` 是否属于本轮授权目录，再交付 `reply`。如果没有合法证词、模型超时、返回格式错误或触发越权/注入，游戏会交付安全回避语，不会把模型原始输出直接展示给玩家。模型改写不得增加新的时间、地点、人物、动机或物品事实。

## 费用和失败处理

每次模型调用会写入用量账本并受每日调用上限限制。超时会自动重试一次；仍失败时本轮标记失败，调查状态和已收到证词保留，玩家可以重试或切回本地演示。当前项目已支持 deepseek-flash；真实网络回归仍应在有效密钥和目标部署环境中执行。
